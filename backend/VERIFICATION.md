# US-04 서버 자체 점검 기록

- 수행일: 2026-11-02
- 실행 환경: Python 3.11.9, FastAPI 0.162.0, SQLAlchemy 2.0.55, PyMySQL 1.2.3.
- DB: 로컬에 일시 생성한 MySQL 8.4.8 컨테이너의 전용 `us04_test` DB. 실제 서비스 데이터와 분리했으며 검증 후 컨테이너를 종료·제거했다.
- 사용 언어 값: `test-language`. 팀 모국어 선택이 아닌 테스트 입력이다.

이 기록은 서버 구현자가 실행한 자체 점검이다. 안내문의 테스트 담당 산출물, first-feature의 공식 실행 확인표, 병합 후 일부러 틀린 구현 시험 결과를 대신하지 않는다.

테스트 의존성에서 Starlette의 httpx 기반 TestClient 지원에 관한 폐기 예정 경고 1건이 발생했으며 테스트는 통과했다. 버전은 requirements.txt에 고정했다.

실제 HTTP 검증의 첫 실행에서는 실행 도구가 가상환경 Python의 심볼릭 링크를 기본 Python으로 해석해 `No module named uvicorn`이 발생했다. 가상환경 경로를 유지하도록 실행 도구를 수정한 뒤 재실행해 통과했다. 애플리케이션 코드를 바꾸거나 테스트 기대값을 낮추지 않았다.

## 이번에 수행하지 않은 것

테스트 담당의 공식 테스트·일부러 틀린 구현 시험, React 화면 구현·브라우저 통합, US-02 수정·재제출 연결, 실제 PDF·Gemini 호출, 공식 기준의 법적 내용 검증, 팀원 5명의 개별 실행은 수행하지 않았다. 전체 US-04 사용자 흐름 통합 완료나 배포 완료를 뜻하지 않는다.

## US-01 추가 자체 점검 (2026-11-03)

- 구현 전 생성 요청의 404 실패를 확인한 뒤 생성·본인 목록을 구현했다.
- 실제 MySQL에서 기존 반려 38개·첨부 7개·생성/목록 35개·기존 DB 업데이트 1개, 총 81개 테스트 통과.
- 입력 경계: 원문 코드 포인트 1·1,000·1,001자, 공백·줄바꿈, 이모지, PDF 1·5·0·6·7개, 정확히 10MB·1바이트 초과, 확장자·시그니처, 허용되지 않은 입력.
- PDF 바이너리 원본과 생성 일시 보존, 추출 텍스트·표시 언어 NULL, 본인 목록·상세, 타인 비노출·미인증·역할 거절 검증. 첨부 저장 실패 시 준비 건도 롤백.
- 기존 필수 언어 컬럼과 원본 없는 첨부 테이블을 재현해 업데이트 후 값 보존·재실행을 확인했다.
- 실제 Uvicorn HTTP로 생성 201·목록/상세 200·잘못된 PDF 422·미인증 401·담당자 목록 403을 확인하고 서버를 종료했다.
- pip check 통과. 기존 TestClient httpx 폐기 예정 경고 1건 유지.
- 일회용 검증 DB는 정리하고 실제 개발 DB는 수정하지 않는다. 화면 연동·공식 인수 테스트·5명 실행 결과로 대신 쓰지 않는다.

## US-01 실제 화면 연결 점검 (2026-11-03)

사용자의 추가 위임으로 mock API를 실제 생성·목록 API로 바꾼 뒤 수행했다.

- npm run build·npm run lint 통과.
- 실제 Chrome·Vite·Uvicorn·일회용 MySQL로 화면에서 모의 PDF를 등록해 201, 목록 표시, 새로고침 후 유지 확인.
- 모의 이용자 1·2 전환 시 목록 분리 확인. 입력 중 계정 변경 차단, 늦은 요청 취소 처리.
- 빈 상황·잘못된 PDF 서버 오류가 화면에 표시되고, 이모지 1,000자 표시·생성도 확인.
- 목록 통신 실패를 주입해 오류·다시 불러오기·회복을 확인. 작성 취소 후 계정 선택이 다시 활성화되는 것도 확인.
- 브라우저 스크립트 오류 없음. 창·서버는 점검 후 종료. 실제 민원 자료나 개인정보는 사용하지 않았다.
- 반려 화면·공식 인수 테스트·5명 각자 실행은 여전히 별도 작업이다.
