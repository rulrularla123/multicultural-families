# UI 디자인 방향

- 작성일: 2026-11-09
- 근거: [PRD 5절](PRD.md), [사용자 흐름](requirements/user-flows.md)

## 방향 한 줄
- 분위기: 차분하고 믿을 수 있는 생활 안내. 법률 용어보다 쉬운 문장이 먼저 보이고, 근거 원문은 한 번 눌러 확인한다.
- 반응형: 휴대폰 폭(360px)부터 데스크톱까지 한 화면 구성. 기본은 한 열, 넓은 화면에서 결과 화면만 두 열(설명 | 원문).
- 기본 언어: 베트남어. 화면 위 VI/KO 전환.

## 토큰

| 이름 | 값 | 어디에 쓰나 |
| --- | --- | --- |
| `primary` | `#1D4F91` | 버튼, 링크, 강조 |
| `background` | `#F7F8FA` | 화면 바탕 |
| `surface` | `#FFFFFF` | 카드 |
| `text` | `#1F2933` | 본문 |
| `muted` | `#52606D` | 보조 문구, 출처 |
| `danger` | `#B42318` | 꼭 확인, 오류 |
| `warning` | `#B54708` | 주의, 원문 확인 필요 |
| `success` | `#067647` | 완료, 일반 |
| `highlight` | `#FFF3BF` | 원문 형광펜 |
| `space` | `8px` | 여백 기본 단위 (배수로 쓴다) |
| `radius` | `8px` | 카드·버튼 모서리 |

상태와 분류는 색만으로 구분하지 않고 항상 글자(꼭 확인 / 주의 / 일반)를 같이 쓴다.

## 모든 화면에 있어야 하는 상태

| 상태 | 어떻게 보이나 |
| --- | --- |
| 빈 화면 | 이유 한 줄과 다음 행동 1개 (예: "아직 분석한 서류가 없어요" + 서류 분석하기) |
| 불러오는 중 | 글자로 "불러오는 중", 해당 버튼 비활성 |
| 오류 | `danger` 색과 글자로 무엇이 왜 실패했는지. 입력값은 지우지 않는다. "다시 시도"가 있으면 같이 |
| 개발용 응답 | `LLM_FAKE`일 때 모든 답변 위에 "개발용 가짜 응답" 띠 |

## 접근성 최소 기준
- [ ] 입력창마다 라벨이 있다
- [ ] 키보드만으로 질문 보내기·분석 시작·체크가 된다
- [ ] 글자 대비 4.5:1 이상 (`text`/`background`, `primary`/`background`)
- [ ] 스트리밍 답변 영역은 `aria-live="polite"`
