## 1. 개요

- 목적: 한국에 사는 베트남 결혼이민자와 한국인 배우자가 체류(F-6 결혼이민) 관련 질문과 서류를, 한국 출입국·체류 법령에 근거해 **베트남어로 바로 이해**하도록 돕는다.
- 사용자
  - 결혼이민자: 한국어 법령·안내문을 읽기 어렵다. 체류기간 연장·변경·신고 의무와 필요한 서류를 모국어로 알고 싶다.
  - 한국인 배우자: 같은 내용을 한국어 원문으로 확인하고 싶다.
- 하는 일
  - **질문하기 (Ask AI)**: 베트남어나 한국어로 물으면 법령을 찾아 베트남어로 답하고, 근거 조문은 한국어 원문으로 같이 보여 준다.
  - **서류 분석하기 (Analyze)**: 체류 관련 서류를 올리면, 개인 상황 질문에 답한 뒤 서류 내용을 꼭 확인할 것 / 주의할 것 / 일반 내용으로 나누고, 주의점과 다음 행동 체크리스트를 준다.
- 하지 않는 일: 체류 허가 여부나 개별 사건의 법적 결론을 판단하지 않는다. 서비스 결과는 민원 접수·허가가 아니며, 법률 정보이지 법률 자문이 아니다.
- 개발 기간: 수업 8주 과정. 4주차까지 동작하는 MVP, 8주차 최종 데모.

## 7. 상태와 LLM의 역할

### 핵심 대상: 서류 분석 건

```
업로드됨 → 질문 대기 → 분석중 → 결과 확인 → 완료
                        ↘ 분석 실패 → (다시 시도) → 분석중
취소: 업로드됨·질문 대기·분석중·결과 확인 → 취소됨
```

| 지금 상태 | 다음 상태 | 누가·조건 |
| --- | --- | --- |
| (시작) | 업로드됨 | 사용자가 유효한 파일을 올림 (글자 추출 실패면 건을 만들지 않고 거절) |
| 업로드됨 | 질문 대기 | 서버가 서류 종류·요약·개인화 질문 생성 완료 |
| 질문 대기 | 분석중 | 사용자가 필수 질문에 모두 답하고 분석 시작 |
| 분석중 | 결과 확인 | 서버가 분석 결과를 저장 (인용 검증 포함) |
| 분석중 | 분석 실패 | LLM 오류·시간 초과·형식 오류 |
| 분석 실패 | 분석중 | 사용자가 다시 시도 |
| 결과 확인 | 완료 | 사용자가 체크리스트 항목을 모두 체크 |
| 진행 중 상태 | 취소됨 | 사용자가 취소. 이후 도착한 분석 결과는 저장하지 않음 |

완료·취소됨은 끝 상태다. 체크리스트 체크를 다시 풀면 결과 확인으로 돌아간다.

### LLM이 하는 일과 코드가 확인하는 일
- LLM: 질의 재작성, 답변 작성, 서류 요약·질문 생성, 서류 분석, 조문 요약(적재 시), 임베딩.
- 코드: 답변의 인용 조문이 실제로 있는지, 현행인지, 인용한 문장이 원문과 맞는지 검증한다. 검증에 실패하면 한 번 다시 생성하고, 그래도 실패한 인용은 "원문 확인 필요"로 표시한다.
- LLM은 체류 허가 가능성·개별 사건의 법적 결론을 판정하지 않는다. 판단이 필요하면 "전문가·출입국 상담 필요"로 안내한다 (`needs_expert`).

### LLM에 보내지 않는 정보
- 식별정보 패턴(외국인등록번호, 주민등록번호, 여권번호, 휴대전화번호)은 보내기 전에 마스킹한다 (`backend/app/common/identity_patterns.py`).
- 원본 파일(바이너리), 익명 사용자 ID는 보내지 않는다.
- 이 패턴으로 모든 개인정보를 잡을 수 없다. 실명·주소는 마스킹하지 못하므로, 실제 서류 대신 모의 서류를 권장한다고 화면에 안내한다.
