## 이미 결정되어 미정에서 뺀 것

- 법령 수집: legalize-kr 마크다운, 미래 시행판이면 이력을 따라 현재 시행판 선택. 법제처 OPEN API 인증 발급을 현재 선행 작업으로 두지 않는다.
- 데이터 범위: 출입국·체류 관련 법령. 하이코리아 매뉴얼은 현재 적재 범위가 아니다.
- 모델 기본값: 답변 `gpt-5`, 질의 재작성·요약 `gpt-5-mini`, 임베딩 `text-embedding-3-large`(1536차원). 모델 ID가 미정이라는 표현을 제거했다.
- 공통 환경: Python 3.12, PostgreSQL 16 + pgvector(Docker, 호스트 5433), React·TypeScript 웹. 패키지 최소 Python 3.11과 구분한다.
- 언어·사용자: 베트남어 기본/한국어 선택, 로그인·담당자 승인 없이 브라우저 익명 ID로 본인 분석 건 분리.
- OCR·실제 서류/실명 처리·로그인·민원 제출·예약·법적 판단은 미정이 아니라 범위 밖이다.

## 결정과 구분해야 하는 실행 확인

- 실제 OpenAI 호출, 베트남어 요약·임베딩 생성, 인용 검증 통과율·숫자 검증·오답 평가가 남아 있다. 수행할 작업이지 모델 미정이 아니다.
- 개인별 설치 권한·네트워크·실행 성공은 각자 직접 확인해 본인 로그에 쓴다. CI 성공을 5명 실행 완료로 바꾸지 않는다.
- 이번 문서 작업에서 개인별 담당·학교 외부 서비스 허용·추가 작업 가능 시간을 새로 정하지 않는다. 팀 확인이 필요한 항목이다.
- '원문 확인 필요'는 인용 검증 실패 시 사용자에게 보이는 문구다. 미정 사항이나 문서의 미완성 표시가 아니므로 유지한다.
