## 제안서(v2)와 다른 점

- 비교 작성: 이주환 / 2026-10-26
- 비교 본문: 미팅 피드백을 반영한 [수정 제안서](../proposal/draft.md)의 Ⅰ-3·Ⅳ-11·Ⅴ. 저장소의 DOCX는 번역·준비 체크 중심의 이전 내용이므로 두 문서를 같은 버전으로 취급하지 않았다. 최종 제출본과 수정 본문의 일치 여부는 팀 확인이 필요하다.
- 비교 대상: 인수 조건을 작성한 [US-01~US-08 검토안](../requirements/backlog.md). 판정은 **유지·축소·미반영·번호 차이**로 구분했다. 이 표는 현재 백로그와의 잠정 비교다. 실제 MVP 포함·제외와 제출 v2가 확인되기 전에는 최종 범위 변경 판정으로 사용하지 않으며, 권길현 담당의 포함·제외 표를 대신 확정하지 않는다.

| 제안서 절 | 제안서(v2)에 적힌 것 | 이 문서(MVP)에서 달라진 것 |
| --- | --- | --- |
| Ⅰ-3 제안 범위 | 상황 설명·관할 관서 확인·서류 업로드 후 공통/관서별 기준으로 AI 대조하고 담당자가 승인한다. 한국어·모국어를 함께 제공하며 첫 데모는 모의 서류를 사용한다. 실제 서류 운영 조건은 후속 확인 대상으로 둔다. | **유지 / 다른 점 없음:** F-6-1 한 유형·외국어 1개 제안, 모든 준비 건의 담당자 승인, 준비 확인과 실제 허가의 구분. **축소:** 현재 작성안의 데모 입력은 등록 공식 원문·유형·언어와 준비 여부이며 PDF 업로드·내용 대조까지 연결되지 않았다. **미반영:** 상황 설명·관서별 추가 기준·두 언어 동시 표시. 이 세 요구는 고객 요청 제외로 판정하지 않고 추가 연결 대상으로 남긴다. 실제 서류는 운영 조건 확인 전 사용하지 않는다는 제한은 유지한다. |
| Ⅳ-11 주요 기능 목록 | 수정 제안서는 F-01~F-10이다. F-03은 서류·상황 대조, F-05는 두 언어 병렬 표시, F-09는 부재 중 점검, F-10은 알림이다. | **번호 차이:** 안내문 기준 5-2의 F-01~F-08을 유지했다. 기존 F-05(확인 요청)→수정 F-06, 기존 F-06(보완/완료)→수정 F-07, 기존 F-07(이력/취소)→수정 F-08, 기존 F-08(알림)→수정 F-10으로 대응한다. **유지:** 담당자 승인·반려, 보완·완료, 이력·취소를 US-04~US-07의 조건으로 작성했다. **미반영:** 기존 F-01~F-04의 PDF·관서 기준·자동 대조 확대, 수정 F-05의 두 언어 표시와 F-09의 부재 중 자동 점검. **상태 차이:** 현재 `안내 검토 대기`와 수정본의 `자동 점검중 → 담당자 승인 대기`를 동일 상태로 취급하지 않는다. |
| Ⅴ 기대 효과와 성공 지표 | 이용자 서류 선택·준비 시간, 담당자 검토·반복 안내 시간, 누락·AI 오지적/미탐지, 자동 점검 종료와 최종 승인 대기 시간을 구분한다. 기준선은 미측정, 수치 목표는 미정이다. | **유지 / 다른 점 없음:** 기준선 미측정·수치 목표 미정, 재방문·비용 절감을 검증된 효과로 주장하지 않는 원칙. **판정 보류:** 지정 자료 5-1은 항목 누락·이해 정답률·목록 작성 시간 중심이다. 현재 인수 조건은 기능의 정상·거절·권한 판단을 다루므로, 인수 조건에 시간 지표가 없다는 이유만으로 Ⅴ의 성공 지표를 축소·제외했다고 판정하지 않는다. 서류 대조 오지적/미탐지·담당자 총 투입 시간·자동 점검과 최종 승인 대기의 측정 계획은 최종 MVP 범위와 함께 별도로 대조해야 한다. 검증 설계안은 같은 유형·관서·기준 버전의 동등한 모의 사례를 사용하고 이용자 작업 시간, 담당자 검토·반복 안내 시간, 승인 대기 시간을 구분해 기록하는 것이다. 참여자·사례 수와 목표값은 후속 측정 계획에서 정하며 임의 수치를 넣지 않는다. |

외부 알림은 현재 US-08의 선택 기능으로 두어 첫 데모의 필수 범위에서 제외했다. 이는 수정 제안서의 알림 후순위 방향과 **다른 점 없음**이다. 최종 범위 합류 때는 필수 검토안 US-01~US-07이 포함 표에서 빠지지 않았는지, 특히 반려 US-04·취소 US-07이 포함되어 있는지 대조한다.
