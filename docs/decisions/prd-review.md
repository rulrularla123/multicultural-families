# PRD 검토 기록 (v0.1 → v1.0)

> **저장 위치:** `docs/decisions/prd-review.md`

> **사용 방법**
> 1. `prd-reviewer`(읽기 전용)에게 `docs/PRD.md`를 검토시켜 나온 지적을 **그대로 옮겨** 적습니다. Claude는 파일을 고치지 않습니다.
> 2. 지적마다 팀이 **반영 / 보류 / 반영하지 않음**을 정하고 **이유**를 씁니다. 모두 반영하지 않습니다.
> 3. **인수 조건은 PRD에 옮기지 않습니다.** 고쳐야 한다면 `backlog.md`를 먼저 고치고, PRD는 `US-xx` 번호로 가리키기만 합니다.
> 4. 반영하기로 한 것만 PM이 PRD에 고칩니다. PRD 맨 위를 `v1.0`으로 바꾸고, 오늘 정한 데이터·디자인이 PRD의 `미정` 칸에 해당하면 채웁니다.
> 5. `>`로 시작하는 안내 문장은 지워도 됩니다.
