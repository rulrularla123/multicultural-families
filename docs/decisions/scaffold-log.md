## 1. 받은 계획과 거른 것

STACK의 A안을 기준으로 빈 프로젝트 실행까지의 범위를 정리했다. 별도로 실행한 Claude의 계획 생성 기록은 없다.

| 계획에 있던 것 | 오늘 함 / 뺌 | 뺀 이유 |
| --- | --- | --- |
| React·TypeScript와 FastAPI 기반 빈 프로젝트 구성 | 함 — 사용자 확인 완료 | 뼈대 실행 범위에 포함 |
| 의존성 설치와 기본 화면·서버 실행 | 함 — 사용자 확인 완료 | 서비스 기능을 붙이기 전 실행 기반 확인 |
| 기본 테스트와 전원 실행 확인 | 함 — 사용자 확인 완료 | 한 환경에서만 실행되는 문제를 점검 |
| MySQL 연결·테이블·시드 데이터 생성 | 뺌 | DB 선택은 MySQL로 유지하되 연결은 후속 기능 구현에서 진행 |
| 로그인·서류 처리·Gemini 실제 호출 | 뺌 | 빈 프로젝트 실행 범위를 넘으므로 후속 작업으로 분리 |
| 화면 꾸미기·외부 배포·운영 설정 | 뺌 | 로컬 뼈대 실행 이후 진행 |

**계획에서 알려준 "막힐 가능성이 있는 곳"**

- Python·Node.js 및 의존성 버전 차이로 팀원별 실행 결과가 달라질 수 있어 전원 실행을 점검했다.
- 화면과 서버의 실행 위치·포트·접속 주소를 구분해 확인하는 대상으로 정리했다.
- 설치 권한·학교 네트워크·개인별 기기 확보는 사용자 확인 결과에 따라 완료로 반영했다.
