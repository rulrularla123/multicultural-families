## 질문지 검토 (5단계)

> Claude에게 질문지를 보여 주고 '빠진 관점'을 물어봅니다. 제안을 그대로 넣지 말고, 채택한 것과 버린 것을 이유와 함께 적습니다.

작성일: 2026-10-13. 사용자의 요청에 따라 Claude의 관점으로 수행한 **모의 검토**와 문서 반영 기록이다. 실제 Claude 실행 응답이나 팀원 상호 검토를 했다는 기록은 아니다. 모의 검토에서는 최근 사례·비유도성·검토 책임·버전 변경·개인정보·측정 기준을 점검했다.

| Claude 관점 모의 검토에서 점검한 관점 | 채택 / 보류 | 이유·반영한 곳 |
| --- | --- | --- |
| 우리 해결책이 유용한지 묻기 전에 최근 준비 사례를 먼저 확인 | 채택 | “도우미가 있으면 편한가요?”는 답을 유도하므로 질문 1을 실제 순서·반복 작업·영향을 묻는 방식으로 작성. H1·H5 검증 |
| 초안 정확성뿐 아니라 검토 가능한 사람·언어·검토 시간 확인 | 채택 | 담당자 사전 승인이 운영 가능해야 하므로 질문 2·6·10과 H2에 반영 |
| 공식 기준의 변경·보완·취소와 완료 의미 확인 | 채택 | 준비 완료와 민원 허가를 혼동하지 않도록 질문 3·4·10, F-02·F-06·F-07에 반영 |
| 정보 수집뿐 아니라 보관·삭제·외부 전달 확인 | 채택 | 질문 7·10에서 최소 데이터·동의·삭제를 묻고 실제 서류·등록번호 입력 제외를 유지 |
| 기존 지원과 비교하고 화면 접근성·읽기 난이도 확인 | 채택 | 통번역 자체를 차별점으로 단정하지 않도록 질문 9에 반영 |
| 모의 비교에 이용자 효과와 담당자 부담을 함께 포함 | 채택 | 질문 8 및 5-1에 누락·이해도·작성 시간과 검토 시간을 함께 기록 |
| 실제 체류 허가율·재방문 감소를 첫 데모의 성공 지표로 사용 | 보류 | 외부기관 결과와 현장 기준선이 없어 효과를 단정할 수 없음. 첫 데모는 가상 사례 비교로 제한 |

Claude 추가 검토에 사용할 요청: “아래 질문지가 실제 사례를 묻는지, 예/아니오로 끝나거나 우리 해결책을 유도하는 표현이 있는지 검토해 주세요. 빠진 이해관계자·예외·검토 책임·개인정보·성공 기준을 찾아 문항 수 8~10개와 우선순위 1~5를 유지하는 수정안을 제안해 주세요.”
