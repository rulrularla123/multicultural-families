| 확인한 내용 | `[사실]` 부산·경남 여성 결혼이민자 136사례를 분석했다. 표 3은 기관에 정보·서비스를 요청하지 않은 이유 중 기관 존재를 몰랐다는 응답을 사례 기준 74.6%로 제시한다. 복수응답이며 표의 응답 비율과 사례 비율을 구분한다. |
| 우리 도메인에 주는 근거 한 줄 | `[추정]` 정보 요청 기관·사람과 이용하지 않은 이유를 구분해 조사한다. |
| 태그 변화 | 연구 자체의 표본·보고 결과는 `[사실]`. 현재 서비스의 필요성과 개선 효과는 `[가정]` 유지 |
| 반영한 곳 | 2-2의 1·5번, 2-5, 4-1 후보 근거, 5-5 질문 1·9 |
| 해석 한계 | 오래된 지역 유의표집 연구다. 74.6%를 현재 전체 결혼이민자의 비율이나 F-6 연장 서류 누락 비율로 일반화하지 않는다. |
