# 백로그 (스토리와 인수 조건)

- 작성일: 2026-11-09
- 기준 문서: [PRD](../PRD.md), [사용자 흐름](user-flows.md), [MVP 범위](../decisions/mvp-scope.md)
- 체크박스는 앞으로 확인할 조건이며 구현·검증 완료를 뜻하지 않는다.
- 숫자 값(파일 10MB·5개, 질문 1,000자, LLM 시간 제한 90초 등)은 팀 설계값이다.

## 공통 조건

- 사용자는 로그인하지 않는다. 브라우저가 처음 열릴 때 만든 익명 ID(`X-Client-Id`)로 분석 건을 구분한다. 다른 익명 ID의 분석 건은 목록·상세 어디에도 보이지 않는다(요청하면 404).
- LLM에 보내기 전에 식별정보 패턴(외국인등록번호, 주민등록번호, 여권번호, 휴대전화번호)을 마스킹한다. 원본 파일과 익명 ID는 보내지 않는다.
- 모든 답변·분석 화면에 "법률 정보이며 법률 자문·체류 허가가 아닙니다" 안내를 사용자 언어로 표시한다.
- 근거로 쓰는 조문은 시행일·폐지일로 계산해 현행인 것만 쓴다. 현행이 아닌 조문을 인용하면 "현행 아님"을 표시한다.
- `LLM_FAKE=true`면 LLM을 부르지 않고 개발용 응답을 쓰며, 모든 문구에 개발용 표시가 붙는다.

## US-01 체류 질문하기

**결혼이민자로서, 체류에 관한 궁금한 점을 베트남어로 묻고 근거가 있는 답을 받고 싶다. 왜냐하면 한국어 법령과 안내문을 직접 읽기 어렵기 때문이다.**

- 기능: F-01 / LLM 관여: 예

### 인수 조건
- [ ] (정상) 1~1,000자 질문을 보내면 베트남어 답변이 생성되는 대로 화면에 나타나고, 끝나면 근거 조문 카드(법령명, 조문 번호, 한국어 원문 일부, 현행 여부)가 1개 이상 붙는다.
- [ ] (정상) 한국어로 물어도 답변은 화면 언어(기본 베트남어)로 나온다. 근거 조문은 항상 한국어 원문이다.
- [ ] (정상) 답변의 모든 인용은 실제로 적재된 조문을 가리킨다. 인용한 문장이 원문과 맞지 않거나 조문이 없으면 한 번 다시 생성하고, 그래도 맞지 않는 인용은 "원문 확인 필요"로 표시한다.
- [ ] (실패) 빈 질문, 공백만 있는 질문, 1,000자 초과는 보내지 않고 이유를 표시한다.
- [ ] (실패) 관련 조문을 찾지 못하면 지어내지 않고 "근거 조문을 찾지 못했다"고 답하며 출입국 상담(1345) 안내를 붙인다.
- [ ] (실패) LLM 오류·시간 초과면 오류 문구와 "다시 시도"를 보여 주고, 질문 입력값은 지우지 않는다.
- [ ] (LLM) 질문에 식별정보 패턴이 있으면 마스킹한 질문만 LLM에 보낸다.
- [ ] (LLM) 체류 허가 가능성이나 개별 사건의 결론을 단정하지 않는다. 판단이 필요한 질문에는 전문가·출입국 상담 필요 표시를 붙인다.

## US-02 근거 조문 보기

**결혼이민자와 배우자로서, 답변의 근거가 된 조문 원문과 관련 조문을 보고 싶다. 왜냐하면 AI 답변이 맞는지 원문으로 확인하고 싶기 때문이다.**

- 기능: F-02 / LLM 관여: 아니오

### 인수 조건
- [ ] (정상) 근거 카드를 누르면 법령명, 조문 번호·제목, 한국어 원문 전체, 시행일, 현행 여부가 보인다.
- [ ] (정상) 그 조문이 위임한 시행령·시행규칙 조문과, 그 조문이 참조하는 조문이 "관련 조문"으로 보이고 눌러서 이동할 수 있다.
- [ ] (정상) 조문별 쉬운 요약이 있으면 화면 언어로 같이 보여 준다.
- [ ] (실패) 없는 조문 ID를 요청하면 404와 "조문을 찾을 수 없음"을 보여 준다.
- [ ] (정상) 현행이 아닌 조문은 "현행 아님"과 폐지일을 표시한다.

## US-03 서류 올리고 질문에 답하기

**결혼이민자로서, 받은 서류나 준비한 서류를 올리고 내 상황 질문에 답하고 싶다. 왜냐하면 같은 서류도 내 상황에 따라 해야 할 일이 달라지기 때문이다.**

- 기능: F-03, F-04 / LLM 관여: 예 / 상태: (시작) → 업로드됨 → 질문 대기

### 인수 조건
- [ ] (정상) PDF·DOCX 파일 1개(10MB 이하)를 올리면 분석 건이 만들어지고 상태가 `업로드됨`이 된다. 글자 추출과 마스킹이 끝나면 서류 종류, 한 줄 요약, 개인 상황 질문 3~5개가 생성되고 상태가 `질문 대기`가 된다.
- [ ] (정상) 질문마다 선택지(또는 짧은 답 입력)와 "왜 묻는지"가 화면 언어로 보인다.
- [ ] (정상) 필수 질문에 모두 답하면 "분석 시작"이 활성화된다.
- [ ] (경계) 정확히 10MB(10,485,760바이트) 파일은 받고, 10,485,761바이트는 거절한다.
- [ ] (실패) PDF·DOCX가 아닌 파일, 10MB 초과, 글자를 추출할 수 없는 파일(스캔·이미지 PDF 포함)은 분석 건을 만들지 않고 이유를 표시한다.
- [ ] (실패) 필수 질문에 답하지 않으면 분석을 시작하지 않고 빠진 질문을 표시한다. 상태는 `질문 대기`로 유지한다.
- [ ] (LLM) 서류 종류·질문 생성 요청에는 마스킹한 추출 텍스트만 들어가고, 원본 파일과 익명 ID는 들어가지 않는다.

## US-04 서류 분석 결과 보기

**결혼이민자로서, 서류에서 내가 꼭 확인해야 할 부분과 주의할 점을 쉽게 알고 싶다. 왜냐하면 기한을 놓치거나 서류가 빠지면 체류에 문제가 생길 수 있기 때문이다.**

- 기능: F-05 / LLM 관여: 예 / 상태: 질문 대기 → 분석중 → 결과 확인 (실패: 분석 실패)

### 인수 조건
- [ ] (정상) 분석을 시작하면 상태가 `분석중`이 되고 진행 단계가 보인다. 끝나면 `결과 확인`이 되고 결과 화면이 열린다.
- [ ] (정상) 결과에는 쉬운 요약 1~2문장, 서류 내용의 조항별 분류(꼭 확인 / 주의 / 일반)와 설명, 주의점(위험·누락·기한·모호함·오래된 내용), 다음 행동 목록, 근거 조문이 있다.
- [ ] (정상) 조항을 누르면 서류 원문이 보이고, 결과가 짚은 문구가 형광펜으로 표시된다.
- [ ] (정상) 서류가 주장하는 내용(기한·금액·근거 법령)은 법령과 대조한 결과로 설명한다. 법령과 다르면 주의점으로 표시한다.
- [ ] (실패) LLM 오류·시간 초과(90초)·형식 오류면 상태가 `분석 실패`가 되고 "다시 시도"를 누르면 같은 답변으로 다시 분석한다.
- [ ] (LLM) 인용 조문은 US-01과 같은 방식으로 검증한다.
- [ ] (LLM) 판단이 어려우면 확신도(높음·보통·낮음)와 전문가 상담 필요 표시를 붙이고, 사용자에게 추가로 확인할 질문을 0~3개 보여 준다.

## US-05 체크리스트로 다음 행동 끝내기

**결혼이민자로서, 해야 할 일을 하나씩 체크하며 끝내고 싶다. 왜냐하면 여러 서류와 기한을 한 번에 기억하기 어렵기 때문이다.**

- 기능: F-06 / LLM 관여: 아니오 / 상태: 결과 확인 ↔ 완료

### 인수 조건
- [ ] (정상) 결과 화면의 다음 행동마다 체크박스와 기한(있으면)이 보이고, 체크하면 저장되어 새로고침해도 유지된다.
- [ ] (정상) 모든 항목을 체크하면 상태가 `완료`가 된다. 하나라도 체크를 풀면 `결과 확인`으로 돌아간다.
- [ ] (실패) `결과 확인`·`완료`가 아닌 건의 체크리스트는 바꿀 수 없다(409).
- [ ] (실패) 없는 항목 번호는 거절하고(422) 저장된 체크는 그대로 둔다.

## US-06 내 분석 건 관리

**결혼이민자로서, 내가 올린 분석 건을 다시 보고 필요 없는 건은 지우고 싶다. 왜냐하면 개인 서류가 서버에 계속 남는 것이 걱정되기 때문이다.**

- 기능: F-07 / LLM 관여: 아니오 / 상태: 진행 중 → 취소됨

### 인수 조건
- [ ] (정상) 내 분석 목록에 내 익명 ID의 건만 최신순으로 보인다(서류 종류, 올린 일시, 상태).
- [ ] (정상) `업로드됨`·`질문 대기`·`분석중`·`결과 확인` 건을 취소하면 상태가 `취소됨`이 된다. `분석중`에 취소한 뒤 도착한 분석 결과는 저장하지 않는다.
- [ ] (정상) 삭제하면 파일·추출 텍스트·결과가 지워지고 목록에서 사라진다.
- [ ] (실패) 다른 익명 ID의 건은 조회·취소·삭제가 안 된다(404).
- [ ] (실패) `완료`·`취소됨` 건은 취소할 수 없다(409). 삭제는 가능하다.

## US-07 법령 데이터 적재

**운영자로서, 체류 관련 법령을 조문 단위로 적재하고 갱신하고 싶다. 왜냐하면 답변과 분석의 근거가 정확한 현행 조문이어야 하기 때문이다.**

- 기능: F-08 / LLM 관여: 예 (조문 요약·임베딩)

### 인수 조건
- [ ] (정상) 적재 명령 한 번으로 대상 법령을 수집 → 조·항·호·목 단위로 파싱 → 검색 단위로 나눔 → DB에 저장한다. 같은 법령을 다시 적재해도 중복이 생기지 않는다.
- [ ] (정상) 조문 사이 관계(법률→시행령·시행규칙 위임, 「다른 법」 제n조 참조)를 추출해 저장한다.
- [ ] (정상) 시행일·폐지일로 현행 여부를 계산해 저장한다.
- [ ] (정상) 조문별 쉬운 요약(베트남어·한국어)과 임베딩을 만든다. LLM 없이 실행하면 요약·임베딩만 건너뛰고 나머지는 적재한다.
- [ ] (정상) `/health`에 적재된 법령 수, 조문 수, 임베딩 수가 보인다.
- [ ] (실패) 수집 중 오류가 난 법령은 건너뛰고 이름과 이유를 출력하며, 이미 적재된 데이터는 지우지 않는다.

## US-08 화면 언어 전환

**결혼이민자와 배우자로서, 화면을 베트남어나 한국어로 바꾸고 싶다. 왜냐하면 부부가 같은 화면을 함께 보기 때문이다.**

- 기능: F-09 / LLM 관여: 아니오

### 인수 조건
- [ ] (정상) 화면 위의 VI/KO 전환으로 모든 메뉴·버튼·안내 문구가 바뀌고, 선택은 새로고침해도 유지된다.
- [ ] (정상) 전환 뒤 새로 받는 답변·분석은 선택한 언어로 나온다. 근거 조문 원문은 언어와 관계없이 한국어다.
- [ ] (정상) 기본값은 베트남어다.

## US-09 샘플 서류 체험 (선택)

**처음 온 사용자로서, 내 서류 없이 샘플로 기능을 체험하고 싶다. 왜냐하면 개인 서류를 올리기 전에 어떻게 동작하는지 보고 싶기 때문이다.**

- 기능: F-10 / LLM 관여: 예

### 인수 조건
- [ ] (정상) 서류 분석 화면에 샘플 서류 2개 이상(가상 문서)이 보이고, 고르면 업로드 없이 분석 건이 만들어진다.
- [ ] (정상) 샘플 서류에는 실제 개인정보가 없고 "가상 문서" 표시가 있다.
