# 사용자 흐름

- 작성일: 2026-11-09
- 핵심 대상: **서류 분석 건**. 상태는 업로드됨 → 질문 대기 → 분석중 → 결과 확인 → 완료 (분석 실패·취소 포함)
- 데모 조건: 로그인 없음(브라우저 익명 ID), 모의 서류 사용, 화면 언어 베트남어

## 흐름 1: 질문하기 (상태 없음)

| 순서 | 누가 | 무엇을 | 결과 |
| --- | --- | --- | --- |
| 1 | 결혼이민자 | 질문하기 화면에서 베트남어로 "체류기간 연장 신청은 언제까지 해야 하나요?"를 입력 (추천 질문을 눌러도 됨) | 질문이 마스킹된 뒤 서버로 감 |
| 2 | 서비스 | 질문을 한국 법령 용어로 바꿔 검색하고, 관련 조문과 위임된 시행령·시행규칙 조문까지 모음 | 근거 후보 |
| 3 | 서비스 | 베트남어 답변을 생성하며 화면에 흘려 보냄 | 답변이 실시간으로 나타남 |
| 4 | 서비스 | 인용 조문을 검증하고 근거 카드(법령명·조문 번호·한국어 원문 일부·현행 여부)를 붙임 | 검증 실패한 인용은 "원문 확인 필요" |
| 5 | 결혼이민자 | 근거 카드를 눌러 조문 보기 화면으로 이동 | 한국어 원문, 관련 조문 |

## 흐름 2: 서류 분석하기 (첫 데모 흐름)

| 순서 | 누가 | 무엇을 | 상태 |
| --- | --- | --- | --- |
| 1 | 결혼이민자 | 서류 분석 화면에서 모의 출입국 통지서 PDF를 올린다 (또는 샘플 서류 선택) | (시작) → **업로드됨** |
| 2 | 서비스 | 글자 추출, 식별정보 마스킹, 서류 종류·요약 파악, 개인 상황 질문 3~5개 생성 | → **질문 대기** |
| 3 | 결혼이민자 | "지금 체류자격은?", "배우자와 함께 사나요?" 같은 질문에 답하고 분석 시작 | → **분석중** |
| 4 | 서비스 | 서류 내용을 법령과 대조해 꼭 확인할 것 / 주의할 것 / 일반 내용으로 나누고, 주의점(기한·누락·위험), 근거 조문, 다음 행동을 만든다 | → **결과 확인** |
| 5 | 결혼이민자 | 결과 화면에서 요약 → 조항별 설명 → 원문 형광펜 → 근거 조문을 본다 | 결과 확인 |
| 6 | 결혼이민자 | 다음 행동 체크리스트를 하나씩 체크해 모두 끝낸다 | → **완료** |

### 예외

| 경우 | 처리 | 상태 |
| --- | --- | --- |
| 글자를 읽을 수 없는 파일 (스캔·이미지 PDF, 빈 파일) | 건을 만들지 않고 이유와 함께 거절 | 변화 없음 |
| 분석 중 LLM 오류·시간 초과 | 분석 실패 표시, "다시 시도" 버튼 | 분석중 → 분석 실패 → 분석중 |
| 사용자가 진행 중에 취소 | 확인 후 취소. 이후 도착한 분석 결과는 버림 | → 취소됨 (끝) |
| 체크를 다시 풂 | 완료에서 결과 확인으로 돌아감 | 완료 → 결과 확인 |
| 다른 브라우저(다른 익명 ID)가 건을 요청 | 보이지 않음 (404) | 변화 없음 |
