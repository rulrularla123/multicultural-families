## 내가 확인한 근거 (실행한 명령과 결과, 파일·링크)

- 별도 로컬 pgvector DB에서 `LLM_FAKE=true`로 `python -m ingest load`를 두 번 실행했다. 두 번 모두 `/health`에 법령 문서 11개, 조문 구조 노드 4,396개, 청크 768개, 임베딩 0개가 표시됐다. 관계 엣지도 2,729개로 같았다.
- 충돌 해결 후 PR 브랜치의 담당 테스트는 pgvector를 포함해 26개 통과했다. 기본 `pytest -q`는 106개 통과·40개 건너뜀이었다. `npm run build`는 청크 크기 경고 1건과 함께 통과했고, `npm run lint`는 오류 0건·경고 4건이었다. GitHub에서 PR #140의 병합 충돌 없음과 `pytest` 성공을 확인했다. 기록 시점에 PR은 열려 있었다. [CI 실행](https://github.com/rulrularla123/multicultural-families/actions/runs/45114911473/job/137495429437)
- [#128](https://github.com/rulrularla123/multicultural-families/pull/128)이 병합된 `main`(`c218096`)에서도 별도로 `TEST_DB=1 python -m pytest -q tests/test_documents_api.py tests/test_acceptance_regression.py`를 실행해 30개 통과를 확인했다. 추출·마스킹 텍스트를 받는 서버 테스트 결과다.
- 수집 요청에 HTTP 500을 반환하도록 모의 실행했다. 기존 법령 원본은 보존됐고 후속 법령에는 수집 요청이 가지 않았다. 재현 결과를 US-07 백로그 검증 기록에 남겼다. [PR #140 변경 파일](https://github.com/rulrularla123/multicultural-families/pull/140/files)
